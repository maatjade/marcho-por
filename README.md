# Marcho Por

Motivos con fuente verificable para marchar en el Perú. Cada motivo se puede imprimir como cartel A3 horizontal con un QR a la noticia original.

## Archivos

- `index.html`: el diseño y el funcionamiento de la página.
- `motivos.js`: la lista de motivos. Para agregar uno, edita solo este archivo; las instrucciones están al inicio.

## Uso

- **Espacio**: otro motivo al azar.
- **← →**: motivo anterior o siguiente.
- **Menú**: todas las secciones.
- Cada motivo tiene su enlace, por ejemplo `#agua` o `#lizeth`.

## Regla de oro

Cada dato lleva medio y fecha. Si la cifra es de parte, se indica. El contexto recoge la otra versión.

## Aviso

Marcho Por es una página independiente que solo recopila noticias publicadas por medios y entidades, con su fuente y fecha. No produce información propia, no está afiliada a ningún partido, organización ni medio, y no convoca marchas. Si encuentras un error, abre un *issue* en este repositorio.
